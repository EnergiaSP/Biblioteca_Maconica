# Breviário Maçônico

Projeto SwiftUI preparado para:
- iPhone
- iPad
- Mac Catalyst
- importação de PDF OCR com Vision/PDFKit
- leitura por data
- índice remissivo com links para páginas/datas
- comentários por dia
- Exportação PDF

O app já inclui o conteúdo auditado do PDF `Breviario maconico OCR.pdf` em
`Resources/breviario.json`. Também é possível importar novamente um PDF pelo
menu `Dados > Importar PDF`.

## Como abrir

Abra `BreviarioMaconicoXXI.xcodeproj` no Xcode e execute o esquema
`BreviarioMaconicoXXI` em um simulador de iPhone, iPad ou Mac Catalyst.
